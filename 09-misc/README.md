### Unsloth Desktop

- 🔗 [Unsloth](https://unsloth.ai/) — free desktop app for local fine-tuning, no code required. Supports 500+ models, LoRA and full fine-tune, 4-bit/16-bit. Shows live loss curves and GPU monitor. Exports directly to GGUF for Ollama and LM Studio.
- 🚨 [Fine-tuning for Beginners](https://unsloth.ai/docs/get-started/fine-tuning-for-beginners)
